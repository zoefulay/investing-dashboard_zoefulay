# My Investing Dashboard

A personal investing dashboard for tracking a $1,000 beginner portfolio, researching stocks/ETFs, keeping a watchlist, and writing an investing plan.

## Run locally
Double-click `index.html` and open it in Safari or Chrome.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `my-investing-dashboard`).
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will publish the site at your Pages URL. Changes pushed to the selected branch will be published automatically.

## Important
This site does **not** connect to Fidelity and does **not** place trades. Never enter a Fidelity password, security answer, or 2FA code here.

The first version uses manually entered current prices and browser local storage. Starter research examples are VOO, MSFT, GOOGL, AMZN, and NVDA; these are research examples, not instructions to buy.
